`get system status` - Model, firmware, serial, HA state
`get system performance status` - CPU, memory, session count, uptime
`diagnose sys top` - Live process list by CPU (q to quit)
`diagnose hardware sysinfo memory` - Memory detail when the unit is in conserve mode
