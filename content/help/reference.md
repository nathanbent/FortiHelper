## Use it for
Finding the command you need while troubleshooting: diagnostic sequences, config templates and lookup tables for FortiGate, FortiSwitch and FortiAP.

## Give it
A search, a topic chip or a kind to narrow the list. Enter your FortiOS version to hide commands that do not apply to it. Where a sheet has `<placeholder>` fields, type a value once and it is filled into every command that uses it.

## You get
Commands to copy one at a time, a whole sheet with Copy all, or a selection built with the + buttons across several sheets. Link copies a URL that opens straight to a sheet. The star pins a sheet under Favourites.

Keyboard: `/` jumps to search, the arrow keys move through and open sheets, Enter opens a sheet or copies the focused command, and Esc clears the search.

## Limits
Values typed into fields are kept in memory only and are gone on reload. Secret fields are masked and filled only into what you copy.

Field checks are warnings: a value that does not look like an IP is still filled in. Version badges cover FortiOS; check FortiSwitchOS and FortiAP firmware differences yourself.
