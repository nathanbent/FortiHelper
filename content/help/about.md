## Use it for
Checking which build you are using, what changed lately, and where to report a problem.

## You get
The version, the commit it was built from and the date of its last change. Quote the version and commit when you report a problem, so the report can be matched to the code.

The newest changes are listed first, with older ones under Earlier changes.

## Limits
The commit and date describe the build you have open, not the latest code: a copy you built yourself, or a cached page, can be behind the source.
