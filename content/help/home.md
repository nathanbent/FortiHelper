## Use it for
Picking a tool. The cards are grouped by job: build config from a list, change config you already have, look up commands, or start from a template.

## Give it
Nothing on this page. Each tool takes pasted text or a loaded file, and the example in an empty input box shows the shape it expects.

## You get
FortiOS CLI as text, to copy or download. Read it before you paste it into a console session: the tools check the format of your input, not the state of your device.

## Limits
Everything runs in this browser tab and nothing is uploaded. The one exception is Object Helper's optional resolved-IP objects, which send the hostnames you list to a public DNS-over-HTTPS resolver.

This browser's local storage keeps the theme, which help panels are open, the Reference favourites, recent sheets and FortiOS version, and a template if you choose to save one. Pasted input and generated config are never stored.
